# 🌍 感恩星球｜Lumi 的每日心光日記

具有 AI 個人化回饋功能的每日感恩日記研究平台。

## ✨ 功能特色

1. **參與者快速登入與自動編號**：
   - 參與者只需輸入自己的名字或暱稱即可登入，系統自動分配研究編號（`P001`、`P002`...），研究者亦可在後台隨時修改編號。
   - 每位參與者的資料完全獨立保存，彼此無法查看。
2. **首次使用 AI 回饋風格設定**：
   - 提供四種預設風格（`🌷 溫柔陪伴`、`✨ 活潑自然`、`🌿 簡短直接`、`💬 像朋友一樣`）與自由輸入補充欄。
   - 設定後儲存於資料庫，亦可隨時在左側「⚙️ 設定」修改。
3. **左側互動式月曆與選單**：
   - 清楚標示「今天」、「書寫中（圓點 ●）」與「已完成（星星 ⭐）」。
   - 選單支援：`📖 今日日記`、`⭐ 心光星空`、`📚 歷史日記`、`⚙️ 設定`。
4. **五階段引導式書寫流程**：
   - **書寫前心情評分**（1～5 分五點量表）
   - **五道固定感恩日記題目**（1. 一個肯定、2. 第一個感恩、3. 第二個感恩、4. 感謝自己、5. 一個檢討），每次顯示一題並附進度條，支援「送出回答」、「跳過這題」與「上一題」。
   - **書寫後心情評分**（1～5 分五點量表）
   - **今日心光回顧 & Lumi 整體 AI 回饋**：串接 Gemini API (`gemini-3.8-flash`)，嚴格遵守不說教、不心理分析、不強迫正向、僅根據實際填寫內容與設定風格給出 1～3 句自然回饋，並永久保存於資料庫中。
   - **親手點亮今日星星**：完成回顧後點亮星星，左側日曆與「心光星空」同步更新。
5. **🔬 研究者管理後台**：
   - 預設管理密碼：`lumi2026`
   - 可直接在網頁後台設定／更新 **Gemini API Key**。
   - 可直接檢視所有參與者的完成篇數、修改研究編號、檢視每日五題原始回答與 AI 回饋。
   - 支援**一鍵匯出 CSV（Excel 相容 UTF-8 BOM 格式）**。

## 🚀 快速啟動方式（Windows）

1. 直接雙擊資料夾內的 `start.bat`，或於終端機執行：
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\pip install -r requirements.txt
   .\.venv\Scripts\python app.py
   ```
2. 打開瀏覽器前往：`http://127.0.0.1:5000`
3. 點擊左下角「**🔬 研究者後台**」（預設密碼 `lumi2026`），即可貼上你的 Gemini API Key 並管理所有研究資料。
